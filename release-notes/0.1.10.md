# 0.1.10

เพิ่ม guardrails และ governance สำหรับ Dependencies / 3rd Party / Libraries / SaaS พร้อมตรวจหลักฐาน Terms of Use, Terms of Service, licenses, policies และ rules ที่ตรงกับการใช้งาน

- ข้อขัดเงื่อนไขร้ายแรงที่ยืนยันแล้ว block affected action และรอ Owner fix/decline; decline ยังคงเป็น acknowledged-unresolved ไม่ใช่สิทธิ์ละเมิดเงื่อนไข
- เก็บ assessments/decisions แบบต่อท้าย อ่านซ้ำอัตโนมัติโดยไม่ต้องส่ง baseline และเปิดกลับมาแก้ได้พร้อมรักษาประวัติ
- ทบทวนใหม่เมื่อ snapshot หรือเงื่อนไข/การใช้งานเปลี่ยนหรือหลักฐานหมดอายุ; ป้องกันการลดสถานะร้ายแรงเพื่อหลบ gate
- JSON, report.md, summary.md, index.md และ prompts แสดง governance แยกจาก Golden findings; เพิ่ม governance-update ที่เขียนได้เฉพาะทะเบียน private ที่อนุญาต
- Exit 3 รวม needs-review; exit 4 คือ governance blocked ส่วน scanStatus ยังคงบอก detector health

แก้เลข candidate ที่ยังไม่เผยแพร่จาก 0.1.20 เป็น 0.1.10 ตามคำสั่ง Owner ไม่มี release 0.1.20 เกิดขึ้นในงานนี้

ผลตรวจ: sync, validate, diff check และ tests 107/107 ไม่มี failed/skipped โดยใช้ existing trusted TypeScript parser และ dotnet host Runtime/hosts ZIP แจกพร้อม SHA256SUMS และตรวจ bytes เทียบ release commit

ข้อจำกัด: Agent/ผู้ทบทวนต้องอ่านเงื่อนไขทางการและยืนยัน inventory จริง Scanner ไม่ตัดสินข้อกฎหมายหรือรับรอง Owner signature อัตโนมัติ ไม่ได้พิสูจน์ Golden conformance ครบทุกข้อหรือ native host activation ไม่มีการติดตั้ง host profiles อัตโนมัติ การลบ V001 ที่ค้างก่อนเริ่มงานไม่รวมใน release commit
