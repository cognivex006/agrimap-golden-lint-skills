# 0.1.12

เพิ่มการตรวจ C# ตามกฎ SonarQube ของ Golden 5.0.5 โดยแยก lint candidate ออกจากผลสแกน SonarQube จริง

- QUALITY-01..03: `be-method-branches` (if/else-if เกิน 7 ต่อ function scope, เกี่ยวกับ S3776), `be-parameter-count` (parameters เกิน 7, S107), `be-nested-ternary` (ternary ซ้อน, S3358)
- QUALITY-05 advisory smells: `be-overload-adjacency` (ADV-01, S4136), `be-caller-info-argument` (ADV-04, S3236), `be-unused-local` (ADV-05, S1481), `be-dispose-suppress-finalize` (ADV-07, CA1816)
- กฎ advisory เป็น smell ที่ทีมตกลงว่าแก้หรือไม่แก้ก็ได้ รายงานเรียงไว้ท้าย ติดป้าย `advisory` และ prompt ระบุว่าค่าเริ่มต้นคือข้อแนะนำ แก้เมื่อผู้ขอสั่งและหลักฐานพิสูจน์ว่าไม่เปลี่ยน behavior/contract เท่านั้น
- Report แสดง Sonar key ที่เกี่ยวข้องใน `authority.externalAnalyzer` พร้อม `resultStatus: not-imported` และ prompt ของกฎเหล่านี้สั่งให้แจ้งผู้ขอตาม notice contract ของ Golden
- ADV-02 (CA1822/S2325), ADV-03 (S1905), ADV-06 (xUnit2032), คะแนน S3776 และ QUALITY-04 เป็น not-implemented

ต้องใช้ Golden agrimap-agent-skills 5.0.5: รุ่น 5.0.4 หรือเก่ากว่าทำให้กฎ backend เป็น blocked พร้อม `SOURCE_MISSING_OR_DRIFT`

ผลตรวจ: sync, validate และ tests 128/128 ไม่มี failed/skipped โดยใช้ existing trusted TypeScript parser และ dotnet host

ข้อจำกัด: เป็น syntax observation ไม่ใช่ผล SonarQube ไม่อ่าน Quality Profile และไม่ resolve type ของโครงการเต็มรูปแบบ
