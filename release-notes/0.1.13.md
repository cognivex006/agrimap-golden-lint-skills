ตรวจลำดับ using/namespace (NS-01) ได้แล้ว และตรวจ overload ที่ไม่อยู่ติดกัน (ADV-01) ใน AgriMap.Platform ด้วย ผูก Golden 5.0.6

- `be-file-layout` (be-main) และ `be-library-file-layout` (be-library): using ที่อยู่หลัง namespace (เช่น namespace ไปอยู่บนสุด ซึ่ง compile ผ่าน และรุ่นก่อนรายงานว่าผ่าน), บรรทัดว่างไม่ใช่หนึ่งบรรทัดระหว่าง using / `namespace Name;` / type และ block namespace ของ library (คงชื่อ namespace ที่ publish แล้ว)
- `be-library-overload-adjacency`: ADV-01 แบบ advisory สำหรับ library ค่าเริ่มต้นคือข้อแนะนำ แก้เมื่อผู้ขอสั่งเท่านั้น ADV-04/05/07 ยังตรวจเฉพาะ be-main
- Source lock ผูก agrimap-agent-skills 5.0.6 (main `fc6ba8b`) Golden 5.0.5 หรือเก่ากว่าทำให้กฎ backend เป็น blocked พร้อม `SOURCE_MISSING_OR_DRIFT`
