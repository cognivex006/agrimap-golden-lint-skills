Golden version ที่ไม่ตรง lock ไม่บล็อกกฎอีกต่อไป และรองรับ Golden 5.0.7 กับ 5.0.8

- Golden รุ่นอื่นของ agrimap-agent-skills ใช้ตรวจได้ รายงานแสดง `SOURCE_VERSION_MISMATCH:<version>` เป็นข้อมูลประกอบ กฎจะ blocked เฉพาะเมื่อไฟล์ reference ที่กฎพึ่งเปลี่ยนจากที่ผู้ดูแลตรวจไว้ (`SOURCE_MISSING_OR_DRIFT`)
- ชื่อ package ผิด, metadata เสีย และ manifests ที่ระบุ version ขัดกัน (`SOURCE_IDENTITY_CONFLICT`) ยังบล็อกเหมือนเดิม
- Source lock ผูก Golden 5.0.8 (main `f926908`) และเก็บ digest ของ 5.0.7 ไว้ใน `compatibleDigests` ทั้งสองรุ่นจึงตรวจได้ทุกกฎ ADV-10..14 ที่เพิ่มใน 5.0.8 ยังไม่มี detector
- รายงานแสดง version ของ Golden ที่ใช้คู่กับ version ใน lock และ provenance เพิ่ม optional `versionMatched`; report schema 1 ยังอ่านรายงานเก่าได้
- เทียบ baseline จาก 0.1.15 แบบ comparable ไม่ได้ เพราะ analysis contract เปลี่ยนตาม lock และ scanner version

ดาวน์โหลด runtime ZIP หรือ hosts ZIP พร้อม SHA256SUMS ของรุ่นนี้ และตรวจ checksum ก่อนแตกลงโฟลเดอร์ว่าง
