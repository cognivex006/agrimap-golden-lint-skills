# AgriMap Golden Lint Skills 0.1.1

เผยแพร่ชุดตรวจ AgriMap Golden แบบอ่านอย่างเดียว พร้อมเอกสารและรายงานที่ระบุขอบเขตการตรวจตามหลักฐาน

- รองรับ scan, explain และ export พร้อมตรวจ identity ของรายงานเดิม
- Detector อัตโนมัติ 6 ตัว, boundary review 4 ตัว และ catalog 21 กลุ่มที่แสดงสถานะครบ
- รองรับ Git snapshot/baseline และ resolve relative TypeScript import/re-export ในหน่วยความจำ
- ตรวจ Golden 4.11.0 และ TypeScript 5.9.3 ด้วย content digest; ไม่ติดตั้งหรือซ่อม dependency ระหว่าง scan
- Runtime ZIP ใช้ distribution allowlist ไม่รวม AGENTS/DEVELOPMENT, tests, source-only guides หรือ .agrimap-agent/
- ตรวจสอบด้วย sync, validate และ tests 23/23 ผ่านบน Windows / Node 26.7.0

ข้อจำกัด: framework/C# semantics, owner-exception input, rename/edited-range matching และ full catalog automation ยังไม่ครบ ข้อเสนอจาก lint ไม่ใช่การอนุมัติแก้ product code

นี่คือ GitHub source/runtime release ไม่ใช่ npm package หรือ host plugin ที่ติดตั้งและตรวจสอบแล้ว ไม่มี product deployment, SQL execution หรือ CI wiring
